怪啖论坛 · 本地启动说明
========================

一、启动
  1. 本机需安装 Node.js（18 或以上，无需安装任何依赖包）。
  2. 在本目录（Web/）打开终端，执行：
       node server.js
     或双击同目录的 启动论坛.bat（如有）。
  3. 浏览器打开： http://127.0.0.1:8787/
     换端口： set PORT=9000 && node server.js
     局域网/服务器暴露： set HOST=0.0.0.0 && node server.js

二、账号
  · 玩家账号：在「创建账号」页直接用并入站点的怪啖论坛制卡工具填卡，
    点工具内「提交到怪啖论坛 · 创建账号」。默认需管理员审核后才能发言/投稿。
  · 登入/切换账号：任意页面点「切换账号 / 登入」，输入 角色名字 + 玩家名字。
  · 测试档案：角色名字 admintest　玩家名字 admin（已过审，含头像/立绘/设卡，供流程演示）。
  · 管理员账号：admin　密码：nopassword
    入口：顶栏「管理后台」——仅当以玩家名字 admin 登入账号时才显示该入口，
    其他账号与未登入时不显示（直接访问 /admin.html 仍需管理员密码）。
    可开关自动审核、审核用户与怪谈、删除聊天消息、发系统公告、
    改公告栏文字；另有「频道管理 / 公告管理 / 帖子管理」三个板块。
  · 管理后台还能修改档案：
      - 查看图片：点击用户/怪谈的缩略图或「查看设卡 / 查看形象」按钮放大查看。
      - 编辑档案：可直接改用户公开资料/真实档案、怪谈名称/类型/范围/机制/对策/共享状态。
      - 头像/人设卡/人物形象（立绘）/怪谈卡面/形象：在各档案编辑弹窗内直接上传替换；
        人物形象对应个人主页的「个人形象 / PORTRAIT」区，也可打黑方块。
      - 帖子管理：可编辑全站任意帖子的标题/正文/所属频道。
  · 打码改为手动黑方块（不再用马赛克/模糊）：
    管理后台编辑用户/怪谈、投稿人编辑自己档案的图片弹窗里，点「黑方块打码」，
    在图上拖动画黑块，点已有黑块即可移除，另有撤销/清空；点「应用」后再保存。
    黑块以相对坐标存在档案的 masks 字段（每图最多 30 块），不写入原图、不破坏画面。
    普通用户查看怪谈档案（列表卡面或点开详情）时看到黑块，点击黑块即本次揭开；
    刷新或下次打开遮挡恢复，不会误删全站打码。原图自动备份为 .orig。
    旧的 masked 布尔字段与 /api/admin/mask 保留但前端已不再使用。
  · 管理员密码已固定为 admin / nopassword，后台不提供修改入口，接口也已移除。

三、数据与迁移
  · 全部数据在 Web/data/（db.json + files/ 图片）。
  · 迁移到服务器：拷贝整个 Web/ 目录（含 data/），在服务器执行 node server.js，
    建议 HOST=0.0.0.0 并用 nginx/caddy 反代 + HTTPS。
  · 备份：直接复制 data/ 目录即可。

四·补充、频道与帖子
  · 初始 4 个频道：怪谈故事、公开情报、调查委托、自由创作；只有管理员能新建频道。
  · 原有怪谈档案已迁移成「怪谈故事」频道里的一条帖子（旧数据仍保留在怪谈档案页）。
  · 已过审账号可发帖（带图，最多 3 张）、回复、点赞（每人每帖一次）。
  · 置顶/删除帖子：仅帖主或管理员，且会标注是「帖主」还是「管理员」操作。
  · 首页频道导航显示各频道帖子数，最热帖子带 HOT↑；人气排行按点赞数取前 5，
    24 小时内发布的帖子带 new。
  · 公告为单条，管理员在后台「公告管理」发布（可带图），新公告覆盖旧公告。
  · 站内消息：回复/点赞/删帖/删评论会记录到「消息」页（仅当事人可见）。
  · 关注（新增）：在他人主页点「关注 / 已关注·取消关注」即可关注（不可关注自己与无主页角色）。
    首次关注某人时，对方「消息」页收到「XXX 关注了你」，点「查看空间」可回看关注者主页；
    取消关注不会推送，重新关注会再推送一次。
    关注的人发布新帖子时，你的「消息」页会收到「你关注的人 XXX 发布了新帖子」推送，点「查看」直达。
    匿名发帖同样推送但不暴露真实网名；取消关注后不再收到。关注关系存在各自账号的 following 字段。
  · 举报（新增）：个人主页名字下方有「⚑ 举报」按钮，点击列出 5 个理由选项
    （发布广告信息 / 可能不是人类 / 发布违法信息 / 发布不实信息 / 没什么纯粹急了），
    选中后给被举报者推送「XXX 举报了你 · 理由：XXX」，点「查看空间」可回看举报人主页。
    后台不审核、不改用户状态，也不会产生其他副作用。

五、与离线工具的关系
  · 两个制卡工具原文件未被修改；双击 HTML 离线使用仍然完全照旧。
  · 论坛的 register/publish 页由 Web/build-native-pages.py 从工具 HTML 自动提取生成
    （样式做了 #cardtool / #guaitool 作用域化，另加 decode() 兼容补丁与提交桥接）。
    若日后修改了工具原版，重新执行一次该脚本即可同步：
      python build-native-pages.py
  · 生成物：site/register.html、site/publish.html、site/assets/cardtool.css、site/assets/guaitool.css。

六、root 服务器监控（/root.html）
  · 独立页面，与 admin.html 完全隔离：独立 root 密码（与论坛管理员无关）、
    独立访问数据文件、不在任何导航中显示，知道地址才能进。
  · 初始 root 密码：rootpassword —— 第一次登入后请点页面右上「改密码」立即修改
    （修改后所有 root 会话作废，需重新登入）。
  · 页面内容：
      - 系统资源：CPU 占用/负载/核数、内存（优先读 /proc/meminfo）、
        磁盘（data 所在分区，fs.statfs，老 Node 回退 df）、实时网速（上下行 B/s，5 秒采样差值）、
        系统/进程运行时长、SSE 连接数、数据文件大小。
        网速在 Linux 读 /proc/net/dev（跳过 lo/容器网卡），Windows 本机回退 netstat -e（近似值）。
      - 访问概览：PV / 独立 IP(UV) / 当前在线（5 分钟内打开过页面）/ 峰值时段 + 24 小时柱状图；
        近 7 天 PV/UV 趋势；访客归属地 TOP（ip2region 离线库，geo/ip2region.xdb，约 11MB）；热门页面 TOP。
      - 内容运营（新增）：帖子/回复/档案/获赞/注册用户总数与今日新增；
        发帖趋势按天堆叠显示「发帖/回复/档案」构成，可切近 7/14/30 天；
        频道热度（各频道帖数/回复/获赞）；活跃用户 TOP10（发帖+回复+档案的动作总数）。
        全部来自内存 DB 聚合，仅 root 可见，不需 root 密码以外任何人看到。
      - 浏览记录明细：时间、IP、归属地、页面、来源、设备/浏览器；支持按日期/IP/页面筛选与分页。
  · 数据存 data/visits.json（服务器本地，已 gitignore，随 data/ 一起备份迁移）：
      天级聚合保留 90 天，明细保留最近约 6000 条；内存聚合，每 10 秒落盘一次。
  · 统计口径：只计站点 .html 页面 GET（与页脚「本日活跃人数」同源）；
      /root.html 自身、API、图片、制卡工具、404 不计入。
  · 安全：所有 /api/root/* 接口（含内容运营 /api/root/content）需 root 会话；普通用户会话与游客均无法读取；页面每 4s/10s/15s 轮询刷新，
    不经 SSE 广播任何访问数据（/api/events 公开，防止访客 IP 泄露）。
    nginx 反代需带 x-forwarded-for（常见默认配置已带，否则记录到的是 127.0.0.1）。

七、成长系统：等级 / 勋章 / 成就 / 签到（新增）
  · 展示位置：个人主页（profile.html）「成长记录」窗口，人设卡与留言板之间；
    「我的主页」（me.html）已改为直接跳转到自己的个人空间，账号编辑走 me.html?edit=1。
  · 等级：按「发帖×10 + 获赞×3 + 档案×20」实时计算成长值，只升不降；
    获赞统计口径含「本人主题获赞 + 本人在任意主题下的回复获赞」；
    称号依次为：无名访客 → 门外徘徊者 → 初入门径 → 热心的听众 → 怪谈记录者 →
    异常调查员 → 档案守夜人 → 诡异杀手 → 一线攻略组 → 新世界（共 10 级），不提供任何特权。
    界面只显示「LV 数字 + 称号 + 进度条 + 数值」，不使用徽章方块图。
    聊天室每条消息在网名后显示 LV 徽标（随消息实时计算，同一批消息按人缓存；已禁封账号不显示）。
  · 勋章：界面暂不显示（u.medals 字段与数据保留，后续再加）。
  · 成就：收进等级右侧的「成就 N/11」小按钮，点开弹窗只显示成就图标与名字，
    不展示解锁条件；未解锁的图标位置显示「?」。数据仍挂在 u.achievements，解锁后不可移除。
    成就清单（11 个，条件仅作后台维护说明，不进 UI）：
      1 你好世界——在聊天室说话（服务端埋点）
      2 刷屏机器——聊天室连续 4 条且中间无人插话（系统消息不算；服务端埋点）
      3 论坛是我家——累计登录论坛 7 天（按北京时间自然日去重记录 u.loginDays）
      4 似乎被盯上了——在「请勿确认」弹窗点了确认（forum.js 埋点 + 服务端白名单）
      5 社区贡献值——发布 5 条帖子（server-forum.js 发帖处埋点）
      6 表情包大师——上传 5 条表情包（表情上传接口埋点）
      7 净坛使者——进行一次举报（举报接口埋点）
      8 因你心动——关注一个人（关注接口埋点，重复关注不重复触发）
      9 这是？——点开「???」的人设卡（profile.html 埋点 + 服务端白名单）
      10 被吃掉了——触发 404 页（404.html 埋点 + 服务端白名单）
      11 跨夜失败——首页过 00:00 彩蛋（home.html 埋点 + 服务端白名单）
    彩蛋类（4/9/10/11）走 /api/achievements/unlock 白名单接口，其他 id 无法伪造解锁。
  · 成就通知：解锁瞬间服务端经 SSE 只推给本人（event: achievement，按连接 uid 过滤），
    前端优先调用浏览器系统通知（Windows 显示为右下角通知气泡），未授权或不支持时退化为右下角页内横幅；
    登入时会顺带申请一次通知权限，也可在成就弹窗里点「开启系统通知」。
    注意：浏览器只允许安全上下文发通知——https 或 localhost 可用，纯 http 的站点域名会被拦。
  · 签到：/api/checkin，北京时间自然日，一天一次；连续/累计天数存 u.checkin，断签清零；
    入口只在首页（index.html）右侧「当前账号」模块内，与「我的主页」「切换账号」同一行，已过审账号可见；
    当日未签到显示「签到」按钮，签完变灰字「已签到 · 连续 N 天」；头部导航、个人主页、成长记录均不放签到入口。
  · 相关接口：/api/achievements（定义列表）、/api/achievements/unlock（白名单解锁）、
    /api/checkin（签到）；等级/成就/签到随 /api/session 与 /api/users/:id/public 输出。

八、个人主页留言回复（新增）
  · 每条未删除留言下方有「回复」按钮，展开单行输入框（回车或点发送提交，再点收起）；
    回复以缩进时间线样式挂在留言下方，最多 50 条，单条上限 500 字。
  · 删除：回复作者本人或管理员可删（软删除，显示「XXX已删除回复」痕迹）；留言被删除后不可再回复。
  · 通知：被回复人（留言作者）收到「XXX 回复了你在个人空间的留言」站内消息，带内容摘要，点查看跳对方主页。
  · 接口：POST /api/guestbook/:留言id/reply、POST /api/guestbook/:留言id/reply-delete；
    回复列表随 GET /api/guestbook/:用户id 一起返回；变更通过 SSE broadcast 实时同步。

九、调查委托模块（新增）
  · 入口：导航栏「调查委托」（quests.html），左侧委托列表（预览图 + 标题 + 红/白标记），
    点任一委托进入二级页面 quest.html?id=… 查看委托详情。
  · 重要委托（kind=main，红色标记）：主线委托，可由管理员在管理后台会话下发布，
    带「异轨投票」——登录用户一人一票、可改票，票数占比实时显示；结案后投票关闭。
  · 普通委托（kind=side，白色标记）：登录用户自行发布，表单字段与教程格式一致：
    委托图片【】/ 委托描述 / 委托地点 / 委托时间 / 委托要求；可选匿名。
  · 委托可挂接论坛原帖（threadId），详情页底部「查看原文」直达 thread.html。
  · 图片：未上传封面时用默认图标 /assets/quest-default.webp；
    上传封面存 data/files/quest-covers/<委托id>.webp；也接受 https 外链。
  · 正文图片：renderText 现在除 https 图床直链外，也接受站内 /files/<分类>/<文件名>.(png|jpg|webp)，
    正文里的旧外链图可转存站内后稳定显示（quest-images 目录）。
  · 接口：GET /api/quests（列表，?kind=main|side）、GET /api/quests/:id（详情）、
    POST /api/quests（发布）、POST /api/quests/:id/vote（异轨投票，仅重要委托）、
    POST /api/quests/:id/status（结案/重开，委托人或管理员）、POST /api/quests/:id/delete（软删）。
  · 数据：db.json 的 quests 数组 + questSeq；变更经 SSE event: quest 实时同步列表与详情。
  · 迁移：migrate_quests.py 把「调查委托」频道里的旧求助帖转成普通委托（幂等，按 threadId 去重）。
